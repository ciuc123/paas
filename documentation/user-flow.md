# Main user flows
## 1. Landing + Sign up
A coach lands on the site, reads the value proposition, and creates an account (sign-up / sign-in).

## 2. Project Creation
The coach starts a new project and answers a lightweight questionnaire (offer, audience, goals, assets like PDFs/videos).

## 3. Blueprint Generation
The system generates a practical project blueprint (funnel, portal, Q&A bot, mini-course structure) via the project generation API.

## 4. Review on Project Board
The coach reviews and edits the generated plan in the projects workspace (projects + project detail page).

## 5. Access & Upgrade Decision
If needed, the coach upgrades through Stripe checkout (upgrade, checkout session, webhook-driven access update).

## 6. Publish MVP Tool
The coach launches a client-facing experience (e.g., content portal or guided flow) and shares it with clients.

## 7. Iterate with Roadmap Guidance
The coach checks the roadmap/content views to prioritize next improvements and validate with real clients quickly.

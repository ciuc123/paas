    Publishing notes

    The roadmap is published at https://paas.ciuculescu.com/roadmap/. Task status remains live because this frontend reads directly from GitHub.

    1. Edit task statuses in .github/instructions/*.instructions.md.
    2. Push the changes to the main branch.
    3. Refresh /roadmap/ to see the updated live status.
    4. Update docs/assets/clerk-config.js with the Clerk publishable key used by the site.
    5. The custom domain remains versioned in docs/CNAME.
